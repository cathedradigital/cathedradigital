# Especificação do módulo Rezar

**Versão:** 1.0.0 · **Estado:** especificado; aceite não verificado.

## Propósito
Apoiar a oração com reverência, sequência clara e fontes identificadas: Liturgia das Horas, Lectio Divina, Rosário, Via-Sacra, Ladainhas e Novenas.

## Experiência
- Cada modalidade tem instruções, sequência e conteúdo próprios.
- Navegar entre etapas sem perder o ponto atual sem aviso.
- Textos litúrgicos/devocionais identificam fonte, edição/idioma e contexto quando necessário.
- Calendário litúrgico usa regra e fonte declaradas; datas móveis consideram contexto de fuso/local.
- Persistência pessoal exige autenticação apenas quando necessária.
- Áudio, temporizador, lembretes ou ações só são anunciados se implementados.

## Critérios de aceite
- [ ] Modalidades abrem e permitem avançar/voltar.
- [ ] Fontes identificáveis.
- [ ] Progresso preservado conforme contrato.
- [ ] Mobile acessível, foco visível e controles nomeados.
- [ ] Estados de carregamento/falha explícitos.
- [ ] Nenhuma função decorativa é apresentada como funcional.

Mapear testes de navegação, etapas, restauração, data/fuso, acessibilidade, mobile e integridade editorial.
