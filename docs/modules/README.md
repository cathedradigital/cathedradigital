## Método de governança
Para cada requisito, localizar o código e os testes correspondentes, executar os testes sem remover ou enfraquecer asserções, registrar SHA/ambiente/resultado/artefatos e só então alterar o estado.

Estados permitidos: **Especificado**, **Mapeado**, **Implementado**, **Verificado**, **Aprovado**, **Bloqueado**, **Não verificado**. O estado inicial é especificado / não verificado. Documentação não é prova de implementação nem de aprovação em produção.
